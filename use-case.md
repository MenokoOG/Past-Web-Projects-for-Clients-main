# Past Web Projects for Clients (2010–2013) — Use Case

**One-liner:** An archive of client websites I built from 2010–2013 as a front-end developer — small businesses, a motorcycle club, a news site, and community projects — published as a browsable portfolio on GitHub Pages.
**Status:** Archived (historical portfolio, live on GitHub Pages)
**Stack:** HTML, CSS, JavaScript, Dreamweaver-era tooling, YUI library, print stylesheets

## Problem
Small businesses and community organizations in that era needed an affordable web presence built by hand. Each project here was a real client engagement: an auto shop (Jacobs Auto), retail businesses (Yoders, Tuttle), a motorcycle club site with chapter pages (RMC), a military-focused news/community site (Military Matters), a local news site prototype (newsbf), an art business (Easel Forge), and my own early resume site.

## What I Built
I hand-built each site to its client's needs: multi-page information architecture (events, galleries, chapters, contacts for RMC; news sections, obituaries, letters, and advertising pages for the news site), custom CSS per brand, ad creatives, coupons, and print stylesheets where clients needed printable pages. Military Matters used the YUI library and page templates; several projects preserve design notes and content documents from the client process. The whole collection is wrapped in an index page and deployed to GitHub Pages so it remains browsable.

## Skills Demonstrated
HTML, CSS, JavaScript, cross-browser front-end development (2010s era), information architecture, client requirements gathering, brand-specific design, print stylesheets, content management by hand, portfolio curation, GitHub Pages hosting

## Outcome / Evidence
All projects shipped to real clients between 2010 and 2013, and the archive is live at https://menokoog.github.io/Past-Web-Projects-for-Clients/. Honestly presented as historical work: the techniques are dated, which is the point — it documents 15+ years of continuous shipping, from hand-rolled HTML through today's full-stack platforms.

## Interview Talking Points
- This archive proves longevity: I was delivering paid client web work while also serving in the Army, over a decade before the current AI-assisted stack existed.
- The range — retail, automotive, a news outlet, a motorcycle club — shows I've always adapted structure and design to the client's actual business, not a template.
